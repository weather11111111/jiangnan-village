# 江南古村 · 3D 生成器

一键生成一座可俯瞰、可把玩的江南古村。每次点击都会得到不一样的水乡格局。

**在线打开**：https://weather11111111.github.io/jiangnan-village/

## 特点

- **单文件、零外部依赖**：3D 引擎已内联进 `index.html`，断网 / 弱网 / 内网都能打开。
- **每次都不一样**：6 个风格族（水乡主河、双河交汇、环水围村、塘浦棋盘、山塘溪村、湖滨渔村），种子码可复制、可用 `#种子` 链接分享。
- **生成规则严格正交**：河流与道路全部横平竖直；沿岸道路强制取直；房屋周围留一圈空地禁建其它房屋；大门一律朝路；农田必近路 / 水 / 宅；宝塔距最近民居 ≥ 16 格；主路两端约 85% 立牌坊；树木在边缘、水边、树丛处加密。
- **把玩方式**：鼠标拖动旋转、滚轮缩放、右键平移；手机单指旋转、双指缩放；点击任意建筑查看名号与介绍；可切换到"入村漫游"用 W A S D 在巷子里行走。
- **时令天色**：春 / 夏 / 秋 / 冬 × 晴 / 雨 / 雪 / 雾 × 晨 / 午 / 暮 / 夜，共 64 种氛围。

## 本地使用

直接用浏览器打开 `index.html` 即可；也可以起本地服务（手机同网访问）：

```bash
node tools/serve.mjs 8123
```

## 开发与校验

源码按片段维护，`index.html` 是组装产物：

```bash
node tools/fetch-vendor.mjs   # 首次：拉取并缓存 three.js 到 _vendor/
node tools/build.mjs          # 组装单文件（含引擎内联）
node tools/check.mjs          # 结构与全部硬约束自检
node tools/verify.mjs 200     # 在 200 个随机种子上断言硬约束
```
